Letakkan file screenshot aplikasi di folder ini dengan nama berikut:

- login.png    -> Halaman Login
- menu.png     -> Halaman Menu
- detail.png   -> Detail Menu
- favorit.png  -> Menu Favorit
- about.png    -> Tentang Aplikasi
- help.png     -> Bantuan & Metode Pembayaran

Cara mengambil screenshot (Chrome):
1. Jalankan: flutter run -d chrome
2. Buka halaman yang ingin diambil gambarnya.
3. Tekan F12 -> Ctrl+Shift+P -> ketik "Capture screenshot" -> pilih "Capture node screenshot" atau "Capture full size screenshot".
4. Simpan file ke folder ini dengan nama di atas.
